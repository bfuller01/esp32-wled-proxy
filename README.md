# ESP32 WLED Proxy

## Project Overview
The ESP32 WLED Proxy is a project designed to enable control of LED strips using the WLED firmware through a simple proxy server. This allows for remote control and monitoring of LED settings via various interfaces.

## Features
- **Remote Control**: Control WLED-enabled devices from anywhere.
- **Web Interface**: A user-friendly web interface to manage LED strip settings.
- **API Access**: RESTful API for integration with other applications or services.

## Getting Started
### Prerequisites
- ESP32 Board
- WLED firmware installed on the ESP32.
- Arduino IDE or PlatformIO for development.

### Installation Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/bfuller01/esp32-wled-proxy.git
   ```
2. Open the project in your preferred IDE (Arduino IDE or PlatformIO).
3. Upload the code to the ESP32 board.
4. Connect to the ESP32 network once the code is uploaded.

## Usage
- Navigate to the web interface using the ESP32's IP address in a web browser.
- Utilize the API endpoints for controlling the LED strip programmatically.
